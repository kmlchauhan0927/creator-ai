CREATOR AI PROTOTYPE V3
Frontend-only prototype. AI outputs are simulated.

Product principle:
UPLOAD ONCE -> AI UNDERSTANDS CONTENT -> SUGGESTED ACTIONS

Deployment plan:
1. Install VS Code and Node.js.
2. Create a GitHub account and repository.
3. Put these three files in the repository.
4. Import the repository into Vercel.
5. Deploy; Vercel gives a free *.vercel.app URL.
6. Test the public site.
7. Only then choose/buy a custom domain after checking name/domain/trademark availability.
8. Add the backend and real AI services after the frontend is online.
